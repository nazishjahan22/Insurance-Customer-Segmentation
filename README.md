# 🛡️ Insurance Customer Segmentation using K-Means Clustering

## 📌 Project Overview

This project implements an **Insurance Customer Segmentation System** using the **K-Means Clustering** algorithm. The objective is to group customers with similar demographic, financial, and behavioral characteristics into meaningful customer segments. These segments help insurance companies understand customer behavior, improve marketing strategies, recommend suitable insurance products, and enhance customer satisfaction.

The project includes a **FastAPI backend**, a responsive **HTML, CSS, and JavaScript frontend**, and is deployed using **Render** (backend) and **Vercel** (frontend).

---

## 🎯 Problem Statement

Insurance companies collect large amounts of customer data, but identifying customers with similar characteristics can be challenging. This project applies **unsupervised machine learning** to discover hidden customer groups without predefined labels.

The identified customer segments can be used to:

* Improve targeted marketing campaigns
* Recommend suitable insurance products
* Enhance customer engagement
* Support business decision-making
* Increase customer retention
